# 실행 결과

생성 결과는 커밋하지 않습니다. 저장소 루트에서 다음 명령으로 현재 코드에 맞는 결과를 만듭니다.

```bash
python run_demo.py
python run_workbench.py
```

- `rehearsal_results.json`: 세 업종·정상 및 오류 주입 변형의 상세 기록.
- `workbench/index.html`: 오프라인 고객서비스 리허설 보고서.
- `workbench/workbench.json`: 보고서의 원시 실행 근거.

이 파일들은 합성 예시에서 실제로 실행한 모의 결과입니다. 실제 기업 API 실행 결과가 아닙니다.
